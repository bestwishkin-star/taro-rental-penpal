# 首页轮播生活拼贴优化设计

## 背景

首页轮播当前主要依赖纯色背景和文字表达，视觉记忆点不足，也没有真实生活场景支撑。用户希望进一步优化首页轮播效果，最好生成适合平台气质的图片，并搭配更好的文字。

本次设计选择「真实生活感照片」方向，并进一步确定为 `A2 生活拼贴 + 信息标签`：用真实居住场景拼贴图承载氛围，用前端叠加标题、副标题和标签，避免把中文直接生成进图片导致变形或难以维护。

## 目标

- 让首页第一屏更有真实居住社区的气质，而不是普通功能入口。
- 通过图片表达“住过的人留下记录”的可信感。
- 通过标题、副标题和标签传达采光、隔音、通勤、街区、费用等核心信息。
- 保持轮播轻量，适配小程序性能和移动端阅读。

## 视觉方向

采用「生活拼贴 + 信息标签」：

- 图片为真实生活感拼贴，不使用豪华样板间或过度商业化素材。
- 每张图片由 2-3 个生活切片组成，例如窗边、书桌、楼下街区、地铁口、菜场、手写笔记等。
- 图片内不放中文文字，所有文案由前端渲染。
- 整体色彩保持温暖、可信、低饱和，避免强广告感。
- 文案层覆盖在图片下方或左下区域，使用半透明暗色遮罩确保可读性。

## 轮播内容

### 1. 窗边房间

**图片主题：**  
清晨或午后自然光落在出租屋窗边，桌面有水杯、书、本子或简单绿植。画面可拼入窗帘、阳台、墙角等生活细节，强调采光和居住感。

**标题：**  
窗边有光，也有答案

**副标题：**  
采光、隔音、通勤，把住过才知道的细节留给后来者。

**标签：**  
采光、隔音、通勤

### 2. 楼下街区

**图片主题：**  
楼下街区的真实日常：小店、菜场、地铁口、夜晚路灯或便利店。画面不追求繁华，而是表达生活便利和周边环境。

**标题：**  
楼下的日常，也算答案

**副标题：**  
菜场、地铁、夜路和烟火气，都是选择一间房的理由。

**标签：**  
街区、地铁、生活便利

### 3. 书桌笔记

**图片主题：**  
桌面上的租房笔记、手机照片、钥匙、票据或地图。画面强调“记录”和“给后来者参考”，适合作为分享入口的情绪承接。

**标题：**  
把居住冷暖写成路标

**副标题：**  
用照片和文字记录真实体验，让下一次选择更有底。

**标签：**  
真实记录、费用参考、避坑提醒

## 交互与动效

- 保留现有自动轮播能力。
- 保留圆点指示器，但视觉上更轻、更像进度提示。
- 每张轮播卡片保留轻微阴影和圆角。
- 不加入复杂视差、过重缩放或长动画，避免影响小程序性能。
- 图片切换应保持平滑，但不制造强干扰。

## 前端实现约束

- 图片素材作为项目本地资源引入，避免依赖远程图片稳定性。
- 中文标题、副标题、标签全部由前端渲染。
- 图片容器预留固定高度，避免轮播加载时发生布局跳动。
- 图片需要有暗色渐变遮罩，保证白色或浅色文字在所有图片上可读。
- 轮播组件继续保持独立，不扩大首页其他区域的改动范围。

## 图片生成要求

生成图片时应遵守：

- 不要在图片中生成中文、英文标语、水印、Logo 或 UI 字样。
- 不要出现过度豪华、样板间、酒店化或房地产广告感。
- 保持真实生活感，可以有轻微胶片感或自然颗粒，但不要模糊主体。
- 画面需要给文字层留出可叠加空间，底部或左下区域不要过于复杂。
- 输出应适合移动端横向轮播卡片裁切。

## 验收标准

- 首页轮播第一眼能看出真实居住分享社区的气质。
- 三张图分别表达房间、街区、记录三个不同主题。
- 中文文案清晰、不变形、可维护。
- 标签信息能帮助用户快速理解每张轮播重点。
- 小屏下标题、副标题、标签不重叠、不溢出。
- 轮播效果比当前纯色背景更有图片感和内容感，但不显得营销化。

## 暂不包含

- 不改首页动作卡片和发布提示区域。
- 不新增后端接口。
- 不新增复杂运营配置后台。
- 不做图片内文字生成。
- 不运行测试或 typecheck。
